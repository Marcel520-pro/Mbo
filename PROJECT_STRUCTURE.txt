🔑 Authentication Flow:
──────────────────────

1. User sends POST /api/v1/auth/login with email & password
2. AuthController receives request
3. AuthenticationManager validates credentials
4. CustomUserDetailsService loads user from database
5. BCrypt compares passwords
6. If valid → return user info + roles
7. If invalid → return error message

─────────────────────────────────────────────────────────────
